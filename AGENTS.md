# Shared Tangle charts

This repo is the sole source and release owner of @tangle-network/charts.
Preserve the static root and optional React entrypoint; React remains an optional peer.
Plot caller-supplied records honestly. Missing values are gaps; do not invent measurements, aggregate results, compress axes silently, or infer status colors.
Use the published @tangle-network/brand tokens as the build-time token source.
Run frozen install, typecheck, affected tests and package/browser proof on a Beelink.
Keep historical evidence and existing public exports when moving ownership.
Ship the tested artifact through the Release workflow; verify its exact public bytes and the requested application consumer.
Only enable npm publication after the actual npm trusted publisher has transferred to this repo.
